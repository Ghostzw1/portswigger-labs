# PortSwigger Web Security Academy — lab portfolio

My learning record for hands-on web application security practice in PortSwigger Web Security Academy. I am building this portfolio to explain how I investigate a vulnerability, interpret the result and identify a suitable defence.

## Lab write-ups

The first SQL injection write-up is being prepared. Completed lab records will be linked here when their notes and evidence have been added.

Each record will cover:

- The lab title, objective and authorized training environment.
- The affected input and how it changes application behaviour.
- The approach taken, including representative requests or payloads.
- The observed result and available completion evidence.
- The root cause, practical impact and remediation.
- What I learned and any assistance used.

## Reading this portfolio

This is a record of learning in deliberately vulnerable training labs. It is not a claim of professional penetration-testing experience or a security certification. Lab-specific findings will distinguish observations from explanations added during documentation.

Write-ups use the [lab template](templates/LAB-WRITEUP.md). Screenshots and request excerpts should contain only information relevant to the demonstration; authentication cookies, session tokens and unrelated personal information do not belong in this public repository.

This repository is an independent learning portfolio and is not affiliated with or endorsed by PortSwigger.
